# 🍔 Sistema de Lanchonete

## 📌 Sobre o projeto

Sistema de Lanchonete desenvolvido como atividade acadêmica no Centro Universitário de Belo Horizonte (UniBH), com o objetivo de colocar em prática os conceitos de Programação Orientada a Objetos (POO).

O projeto simula um contexto de gerenciamento de uma lanchonete, servindo como exercício prático para desenvolvimento de soluções utilizando programação orientada a objetos.

## 🎯 Objetivos de aprendizagem

- Praticar os fundamentos da Programação Orientada a Objetos.
- Desenvolver a capacidade de modelar situações do mundo real através de classes e objetos.
- Aplicar os conhecimentos adquiridos durante a formação acadêmica.
- Exercitar a organização e estruturação de código.
